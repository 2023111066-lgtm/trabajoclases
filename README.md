Cómo ejecutar
1. git clone https://github.com/2023111066-lgtm/trabajoclases.git
2. cd trabajoclases
3. python main.py

Al iniciar, el sistema crea la base de datos sihc.db con las tablas paciente y cita.
Módulos
- Pacientes: registrar, listar, buscar, consultar y actualizar.
- Citas: programar, listar, reprogramar y cancelar.
